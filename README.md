# dsaQuestions

This repository contains 150 Data Structures and Algorithms questions with solutions, organized by difficulty level.

## Files Included

- **150_Complete_DSA_Questions_Solutions.docx**: Complete Word document containing all 150 problems with solutions
- **complete_dsa_document.py**: Python script used to generate the Word document

## Problem Distribution

- **76 Easy Problems**: Fundamental concepts and basic algorithms
- **54 Medium Problems**: Intermediate level problems requiring more complex thinking
- **20 Hard Problems**: Advanced problems requiring sophisticated algorithms and optimization

## Solution Format

Each problem includes:
- Clear problem statement
- Brute force solution (for learning the basic approach)
- Optimized solution (for better time/space complexity)
- Student-friendly code without excessive comments

## Topics Covered

- Arrays and Strings
- Linked Lists
- Binary Trees and BST
- Dynamic Programming  
- Graph Algorithms
- Sorting and Searching
- Hash Tables
- Stack and Queue
- Recursion and Backtracking
- Two Pointers and Sliding Window

All solutions are written in Python and designed to help students understand both basic and optimized approaches to problem-solving.
